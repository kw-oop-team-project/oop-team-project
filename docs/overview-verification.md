# 체육시설 현황 탭 구현·검증

검증일: 2026-11-24 (Asia/Seoul).

## 작업 범위

- 현황 탭과 통계 전용 모듈·지도 경계·관련 테스트만 추가했습니다.
- `app.py`에서는 현황 분기에 별도 서비스를 연결했습니다. 홈과 시설 찾기 실행 흐름은 유지했습니다.
- 현황에는 시설명 검색, 개별 시설 목록·상세정보·예약 안내, 시설 찾기 이동 버튼이 없습니다.
- 현황에서 예약 API를 호출하지 않습니다. 선택한 시설 정보 API 하나만 조회합니다.
- 기존 `FacilityAnalyzer`의 네 가지 집계 인터페이스를 API 객체와 등록자료 기준에 맞게 확장했습니다.

## 화면과 집계 기준

- 기본 출처는 국민체육진흥공단의 서울 공공시설 자료이며 서울시 자료로 전환할 수 있습니다.
- 시설 종류와 간이운동장 포함 여부가 통계 카드·지도·그래프·집계표에 함께 적용됩니다.
- 등록 시설 수, 최다 등록 자치구(동률 모두 표시), 보유 자치구 수 `/25`를 표시합니다.
- 25개 자치구 분포 지도와 막대그래프, 종류별 건수 그래프, 자치구별·종류별 건수 및 비중 표를 제공합니다.
- 같은 출처에서 동일 시설 ID가 반복되면 한 건으로 셉니다. 다른 ID는 이름·주소가 같아도 별도 등록 항목입니다.
- 두 출처를 합산하지 않으며, 제공기관의 시설 종류를 종목 검색용 별칭으로 임의 통합하지 않습니다.
- 비중의 분모는 현재 조건에 해당하는 등록 항목 합계입니다. 지도 좌표가 없는 항목도 집계합니다.
- API 오류·키 미설정 시 0건 통계로 바꾸지 않습니다. 출처도 자동 변경하지 않습니다.
- 일부 응답은 수신 자료 기준 수치·순위로 표시하며, 지역별 0건이 실제 시설 부재를 뜻하지 않음을 안내합니다.
- 정상 응답 스냅샷은 300초 동안 재사용합니다. 출처별 새로고침은 검색용 캐시와 독립적입니다.
- 표시하는 조회 완료 시각은 원본 자료의 갱신일이나 시설 자료의 기준 연도가 아닙니다.

## 파일

| 파일 | 역할 |
|---|---|
| `src/facility_analyzer.py` | ID 반복 제외·조건 선택·자치구/종류별 집계·동률 처리 |
| `src/overview_data.py` | 현황 전용 출처별 API와 스냅샷 캐시·조회 시각 |

경계 자료는 지역별 통계 표시용이며 최신 경계 측량이나 시설 위치 탐색용이 아닙니다.
원본 파일은 수정 없이 포함했고, 차트에 전달할 때 지역명과 집계값을 결합합니다.

## 검증

- 전체 66개 테스트 통과: 기존 53개와 신규 현황 테스트 13개.
- 합계와 25개 구의 합 일치, 종류별 비중 합계, 시설 없는 구, 동률, 0건, ID 반복과 동명 시설, 제공기관 분류 보존을 검사했습니다.
- 출처별 캐시·만료·강제 갱신·일부/오류 응답 재시도, 키 없는 경우 HTTP 미호출을 검사했습니다.
- 실제 `app.py`의 출처 변경·종류 변경·간이운동장 제외·조건 복원·검색 상태 독립성을 검사했습니다.
- 홈 API 미호출과 기존 검색·상세·예약·메뉴 복원 테스트는 통과했습니다.
- 현황에서 예약 API 미호출, 시설 검색 입력·시설 카드·검색 이동 버튼 부재를 검사했습니다.
- 지도와 그래프의 Vega-Lite 명세를 검증하고 실제 API 집계값으로 PNG 렌더링하여 25개 구 색상·경계와 그래프 축·한글을 확인했습니다.
- 로컬 Streamlit 서버 `/`와 `/_stcore/health`에서 HTTP 200을 확인했습니다.
- 브라우저 접근 호스트가 없고 Chrome 창이 최소화되어 실제 페이지 배치·툴팁·모바일 화면의 브라우저 검증은 완료하지 못했습니다. AppTest 및 차트 이미지 검증과 구분합니다.
